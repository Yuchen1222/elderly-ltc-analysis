# 高齡族群長照使用之時間變化與影響因素分析

> **Interactive Dashboard** — 民國 108–112 年長照服務使用趨勢分析與需求評估系統

作者：陳祥瑋・陳紀宇・鄭博仁・詹鶴章・黃宇晨

---

## 研究摘要

台灣已正式邁入超高齡社會，本研究以民國 108 至 112 年之銀髮安居模擬資料為基礎，
透過邏輯斯迴歸模型探討高齡族群長照服務使用的時間趨勢與主要影響因素。

**核心發現：**
- 長照使用率於民國 110 年達到高峰（約 15.9%）後逐年下降，揭示需求與服務間的落差
- 身心障礙嚴重度（OR ≈ 1.61）與年齡（OR ≈ 1.07）為最強正向預測因子
- 家庭支持對正式長照具有替代效果；低收入族群存在使用障礙

| 頁面 | 內容 |
|------|------|

## 本機執行

```bash
# 安裝套件
pip install -r requirements.txt

# 產生模擬資料（只需執行一次）
python data/generate_data.py

# 啟動 Dashboard
streamlit run app.py
```

瀏覽器開啟 [http://localhost:8501](http://localhost:8501)
